# PintOS virtual memory

A CS 439 group project snapshot adding demand-paged virtual memory, including frame eviction, swap, lazy loading, and stack growth. This repository includes the course-provided operating-system base as well as the submitted changes.

## Source and attribution

The base PintOS code is credited to Stanford University and retains the upstream `LICENSE` file. This is a course modification of that base, not an operating system authored from scratch. The original submission contained student identifiers in course README files and planning logs; those files are excluded from this public copy. Contributor names in source comments are retained where they document pair work.

## Build and testing

The archived Makefiles and tests are included where available. This public snapshot has not been rebuilt or rerun in the current Windows environment. Check the included Makefile and course-specific dependencies before attempting to build. No performance or full-suite passing claim is made here.
